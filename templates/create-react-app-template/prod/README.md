# create-react-app-template - Production Stage

This is the **production** version of the `create-react-app-template` template.

## Current Status

This folder is a placeholder. The template will be promoted here from the int stage.

## Production Notes

This is the final stage. Templates in production are:

- Visible to all users (based on visibility settings)
- Considered stable and ready for production use
- Subject to stricter change management

## Making Changes

To update a production template:

1. Make changes in the **dev** stage first
2. Bump the version and promote to **int**
3. Test thoroughly in int
4. Bump the version again and promote to **prod**

Never make direct changes to production templates.
